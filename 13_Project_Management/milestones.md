# Eight-week milestone plan

| Week | Milestone | Exit condition |
|---|---|---|
| 1 | Prior-art and dataset audit | Critical full-text access attempts documented; provenance, license, context, and metadata audited |
| 2 | Gap/feasibility decision | Supervisor-reviewed question and novelty matrix; continue, narrow, or stop |
| 3 | Annotation pilot | Draft schema, pilot labels, agreement and ambiguity report |
| 4 | Baselines | Reproducible detector-only and conventional-shadow baselines |
| 5 | Observability method | Operational definition, features/labels, first implementation |
| 6 | Comparisons/ablations | Four planned systems compared on fixed splits |
| 7 | Robustness/writing | Error analysis, calibration, limitations, first paper draft |
| 8 | Reproducibility/review | Clean runs, configs, documented results, supervisor review |

Planning target only, not a guarantee of publication. If novelty or dataset feasibility fails, revise the question rather than rushing to train.
