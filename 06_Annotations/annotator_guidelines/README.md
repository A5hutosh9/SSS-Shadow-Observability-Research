# Annotation protocol — draft

1. Annotate independently before discussion.
2. Use full available image context; avoid tight crops that hide the expected shadow region.
3. Keep **unobservable**, **not assessable**, and **no shadow evidence** separate.
4. Record reasons for weak, ambiguous, unobservable, and not-assessable labels.
5. Do not infer range, height, or geometry unless supported by metadata or a validated method.
6. Log and adjudicate disagreements.
7. Pilot on a shared subset, measure inter-annotator agreement, revise definitions, then freeze the protocol.
8. Keep annotators blind to model predictions during ground-truth annotation.

Schema is provisional and requires pilot/supervisor review.
